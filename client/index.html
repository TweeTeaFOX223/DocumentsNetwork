DocumentsNetwork のシーケンス図
このアプリは、クエリ文書を MeCab で分かち書きし、Apache CGI 側で類似文書検索・構成グラフ生成・可視化座標計算を行い、最後に client がネットワーク図と評価結果を表示する構成です。
シーケンス図

各サーバーの役割

  • client: クエリ文書アップロード、Visual / Graph / Search の選択、グラフ描画、文書詳細表示、Request/Response Log、定量評価表示を担当します。
  • server-mecab: `normalText` を前処理し、MeCab により `wakachiText` を生成します。Apache CGI に渡す前の自然言語処理の入口です。
  • Apache CGI(main.cgi): クエリとデータセットを比較し、類似文書集合の決定、類似貢献度計算、構成グラフ生成、可視化座標計算、JSON レスポンス出力を行います。
  • 0_data / C内部処理: `uid.txt`、`doc.txt`、`wakachi.txt` をもとに、検索対象文書と中間計算データを扱います。

研究内容の要点

  • 文書同士が「どの説明語の観点で類似しているか」を類似貢献度ベクトルとして表し、その構造をネットワーク図で可視化します。
  • Graph 手法では KNN / MST / HML により、どの文書対をエッジで結ぶかを決めます。
  • Visual 手法では SE / MDS / CE / KK により、ノードを 2 次元平面へ配置します。
  • 説明語ごとのカテゴリ色、ノード位置、エッジ構造を同時に見ることで、検索結果全体の類似構造と局所的な文書群を把握しやすくしています。
  • 可視化品質は `cv`（エッジ長の変動係数）と `on`（ノード重なり指標）で定量評価し、複数手法の比較も client 上で確認できます。
